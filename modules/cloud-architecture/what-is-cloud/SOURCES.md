# Sources (fact-checked 2026-10-02, before building)

Full notes: scratchpad `cloud/m01-facts.md`.

- Mell & Grance, NIST SP 800-145, "The NIST Definition of Cloud Computing" (Sept 2011; still current): definition, five essential characteristics, three service models, four deployment models ("may exist on or off premises"); pay-per-use appears in a footnote.
- History: Amazon S3 (13 Mar 2006); EC2 beta (24 Aug 2006, generally available Oct 2008); Google App Engine preview (7 Apr 2008); Windows Azure commercially available Feb 2010, renamed Microsoft Azure (2014). Salesforce founded 1999, launched Feb 2000.
- Scale (providers' pages, 2 Oct 2026): AWS 39 regions, 124 availability zones; Google Cloud 43 regions, 130 zones; Microsoft "80+ regions" (no official zone total).
- Synergy Research Group, Q2 2026 cloud infrastructure market (30 Jul 2026): AWS 28%, Microsoft 20%, Google 15% (analyst estimate).
- IEA, Energy and AI (2025) and April 2026 update: conventional data centres 10–25 MW, hyperscale AI 100 MW+ (≈ 100,000 households); data centres ≈ 485 TWh in 2025, ≈ 950 TWh by 2030.
- Billing: EC2 per second with a 60-second minimum (Linux, Windows, RHEL, Ubuntu Pro); Compute Engine 1-minute minimum then per second; Azure VMs per minute.
- Services: AWS Elastic Beanstalk, Azure App Service, Google Cloud Run (Google recommends it over App Engine for new apps), OpenStack 2026.2.
- Flexera 2026 State of the Cloud (753 respondents): 73% hybrid (vendor survey). 37signals: spent $3.2M on cloud in 2022; projects ~$10M saved over five years after moving to its own hardware in colocation (their own figures).
- The demand curves and unit costs in step 3 are made up for illustration.
