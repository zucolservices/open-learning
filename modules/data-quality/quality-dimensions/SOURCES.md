# Sources: Dimensions of data quality (fact-checked 2026-10-04)

- DAMA UK Working Group, "The Six Primary Dimensions for Data Quality Assessment", October 2013 (definitions, measures and examples; "not universally agreed"; not prescriptive).
- R. Y. Wang and D. M. Strong, "Beyond Accuracy", JMIS 12(4), 1996 (four categories, fifteen dimensions in the final framework).
- ISO/IEC 25012:2008, Data quality model (15 characteristics; inherent and system-dependent; confirmed 2025); iso25000.com summaries.
- ISO 8000-1:2022, Data quality — Overview.
