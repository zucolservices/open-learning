# Sources: Security headers and CSP (fact-checked 2026-10-07)

- W3C CSP Level 2 Recommendation (15 Dec 2016); CSP Level 3 Working Draft (16 Sept 2026). web.dev, "Mitigate cross-site scripting (XSS) with a strict Content Security Policy".
- Weichselbaum, Spagnuolo, Lekies & Janc, "CSP Is Dead, Long Live CSP!", ACM CCS 2016: 94.72% of 26,011 unique policies bypassable.
- RFC 6797, HSTS (Nov 2012); hstspreload.org (preloading not generally recommended). RFC 7034, X-Frame-Options (Informational).
- MDN and OWASP Secure Headers Project: X-Content-Type-Options, Referrer-Policy, Permissions-Policy, X-XSS-Protection (don't set or set 0), COOP/COEP/CORP.
- MDN HTTP Observatory (launched Jul 2024). securityheaders.com (Probely, now part of Snyk).

The attack list and header toggles are illustrative.
