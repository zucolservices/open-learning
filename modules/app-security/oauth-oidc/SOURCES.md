- RFC 6749, OAuth 2.0 (Oct 2012). OAuth 1.0 (Dec 2007; RFC 5849, Apr 2010). OpenID Connect Core 1.0 (25 Feb 2014); ISO/IEC 26131:2024.
- RFC 7636, PKCE (Sept 2015). RFC 9700, OAuth 2.0 Security Best Current Practice (Jan 2025): password grant MUST NOT be used; implicit grant SHOULD NOT be used; exact redirect URI matching.
- draft-ietf-oauth-v2-1-16 (3 Sep 2026): OAuth 2.1 still a draft. oauth.net: OAuth is not an authentication protocol.
