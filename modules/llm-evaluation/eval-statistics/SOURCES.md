# Sources: Error bars for evals (fact-checked 2026-10-05)

- Evan Miller, "Adding Error Bars to Evals: A Statistical Approach to Language Model Evaluations" (arXiv 2411.00640, 1 Nov 2024; Anthropic blog 19 Nov 2024): report SEs, cluster, reduce variance by resampling, paired differences, power analysis; "don't touch the thermostat".
- Standard error of a proportion √(p(1−p)/n); E. B. Wilson (1927) score interval.
- Efron, "Bootstrap Methods" (1979).
- Sample-size figures are standard two-proportion approximations (80% power, α = 0.05), computed here, not from Miller.

The 80% "true" system and simulated runs are illustrative.
