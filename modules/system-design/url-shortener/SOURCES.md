# Sources (checked 2026-09)

- RFC 9110 §15.4: 301 Moved Permanently and 308 Permanent Redirect are cacheable by default (heuristically); 302 Found and 307 Temporary Redirect are not, unless cache headers say so.
- Base62 key space: 62⁶ ≈ 56.8 billion, 62⁷ ≈ 3.52 trillion (arithmetic).
- Birthday bound: P(any collision) ≈ 1 − e^(−n(n−1)/2N); expected occupied-slot collisions n − N(1 − e^(−n/N)).
- Load-test capacities and latencies are illustrative, stated as such in the step.
