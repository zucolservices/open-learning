- Neo4j docs, "What is a graph database?" (nodes, labels, properties; relationships with start, end, one type, direction, properties; no JOINs).
- W3C, RDF 1.1 Concepts and Abstract Syntax, Recommendation 25 Feb 2014 (triples: subject, predicate, object); RDF 1.2 Concepts, Candidate Recommendation Snapshot 7 Apr 2026 (triple terms).
- P. Rathle, Neo4j blog, 17 Apr 2024, and ISO/IEC 39075:2024 (GQL published 12 April 2024; first new ISO database language since SQL).
- Neo4j Cypher manual introduction; Neo4j fraud detection use case ("operate in rings, not in isolation").
