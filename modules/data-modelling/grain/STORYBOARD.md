# Storyboard: The four-step design process

1. **Decide what one row means** (story): tree, hectare or forest.
2. **Design a supermarket fact table** ⭐ (step-through): pick process, grain, dimensions and facts with feedback; the table takes shape; questions each grain can answer.
3. **Never mix grains** (explore): receipt totals inside line items double the sum.
4. **Start atomic** (explore): three grains vs four questions.
5. **Which step?** (checkpoint `which-step`).
6. **What to remember** (wrap).
