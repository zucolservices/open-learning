# Sources: Modelling for NoSQL (fact-checked 2026-10-04)

- AWS, DynamoDB Developer Guide: "NoSQL design" best practices (know the questions first; contrast with RDBMS; few tables) and "Data modeling foundations" (single-table design; item collections; downsides; multiple-table design "good and sufficient").
- MongoDB manual: data modelling ("accessed together should be stored together"), embedding (denormalised), referencing (normalised), best practices decision table, limits (16 MiB maximum BSON document size).
