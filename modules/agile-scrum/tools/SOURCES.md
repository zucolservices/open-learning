# Sources (fact-checked 2026-09-28, before building)

Full notes and the full mapping table: scratchpad `agile/m20-facts.md`. All names from vendor documentation and changelogs, fetched 2026-09-28.

- Atlassian: Jira Software and Work Management merged into "Jira" (May 2024); "issues" renamed "work items" (from March 2025), "projects" to "spaces" (from September 2025); Epic > Story > Subtask; "Story point estimate"; Sprint Report, Burndown Chart, Velocity Chart. Workflow advice: "include only the statuses and transitions you need".
- Microsoft Learn (Azure Boards): process templates (Agile, Scrum, CMMI, Basic) and their item types; Effort / Story Points / Size; Sprints, Taskboard, sprint burndown, velocity.
- GitHub Docs and changelog: Projects Iteration field, board layout, Insights charts; sub-issues and issue types GA 9 April 2025; Projects (classic) retired 23 August 2024.
- GitLab Docs: issue boards, iterations and cadences, weights, epics (now work items), burndown/burnup; Premium/Ultimate tiers.
- Linear Docs: Cycles, Backlog status, Triage, Projects, Initiatives, estimate scales, cycle graph.
- Taiga (MPL-2.0 backend / AGPL-3.0 frontend), OpenProject (GPL-3.0; sprints separate from versions since 17.3), Plane (AGPL-3.0; Cycles), Redmine (GPL-2.0; Scrum via plugin), WeKan (MIT; Kanban).
- Agile Manifesto (2001): "Individuals and interactions over processes and tools".
