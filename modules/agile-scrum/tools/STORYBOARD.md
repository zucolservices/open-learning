# The same board, every tool: storyboard

1. **Same trip, different app** (analogy): one train journey shown by three booking apps; colour-matched fields (reference, train, coach, berth) carry different names.
2. **One board, six tools** ⭐ (animated infographic): one mock Scrum board (backlog, grouping, Sprint, board, item, estimate, breakdown, chart); switch Jira / Azure Boards / GitHub / GitLab / Linear / open source and the labels cross-fade to each tool's names; tap a label to highlight its row in the full mapping list; a per-tool note (renames, paid tiers, process templates, licences).
3. **Configure or leave alone?** (sort): columns matching real flow, twelve statuses, visible DoD, mandatory fields, per-developer velocity.
4. **What to remember**: ideas first, start simple, mind the tiers, expect renames; "Individuals and interactions over processes and tools".
