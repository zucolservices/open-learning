# Sources: Messaging building blocks (fact-checked 2026-10-04)

- G. Hohpe and B. Woolf, Enterprise Integration Patterns (2003), enterpriseintegrationpatterns.com: Message Channel, Point-to-Point Channel, Publish-Subscribe Channel, Command/Document/Event Message, Request-Reply, Correlation Identifier, Dead Letter Channel, Invalid Message Channel, Guaranteed Delivery, Competing Consumers, Idempotent Receiver.
- AWS docs: Amazon SQS dead-letter queues (maxReceiveCount); Amazon SNS fanout to SQS.
- Microsoft Learn: Azure Service Bus queues, topics and subscriptions; dead-letter queues.
- Google Cloud: Pub/Sub basics; dead-letter topics (set on the subscription).
- RabbitMQ: AMQP 0-9-1 concepts (four exchange types).
- Apache Kafka 4.3 KafkaConsumer javadoc (consumer groups).

The simulation's messages, retry count and receivers are illustrative.
