# Sources: Linear and logistic regression (fact-checked 2026-10-06)

- Legendre, _Nouvelles méthodes pour la détermination des orbites des comètes_ (1805); Gauss, _Theoria motus_ (1809).
- Cauchy, "Méthode générale pour la résolution des systèmes d'équations simultanées", Comptes rendus (18 Oct 1847).
- Verhulst (1838; "logistique" 1845); Berkson (1944, "logit"); Cox, "The regression analysis of binary sequences" (1958).
- scikit-learn 1.9 docs: LinearRegression (ordinary least squares, no regularisation); LogisticRegression (L2, C=1.0 default; `penalty` deprecated in 1.8, removed in 1.10; use `l1_ratio`).

House data, churn weights and the logistic example are illustrative; the fit and gradient descent run live.
