# Sources: The ML project lifecycle (fact-checked 2026-10-06)

- CRISP-DM 1.0 (Chapman et al., 2000; begun 1996 by Daimler-Benz, SPSS, NCR, OHRA): six phases; cyclical.
- M. Zinkevich, "Rules of Machine Learning: Best Practices for ML Engineering" (Google): Rule #1 "Don't be afraid to launch a product without machine learning"; metrics first; simple first model.
- Sculley et al., "Hidden Technical Debt in Machine Learning Systems" (NIPS 2015): Figure 1, not to scale.
- CrowdFlower Data Science Report (2016); Anaconda State of Data Science (2020: ~45%; 2021: ~39%).
- Gartner surveys (2019; 2022): ~53–54% of AI projects reach production. Gartner 2018 "85%" was a prediction about erroneous outcomes; VentureBeat 2019 "87%" is unsourced.
- Google Cloud, "MLOps: Continuous delivery and automation pipelines in machine learning"; Kreuzberger et al. (2023), MLOps definition.
