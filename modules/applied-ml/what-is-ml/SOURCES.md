# Sources: What machine learning is (fact-checked 2026-10-06)

- A. L. Samuel, "Some Studies in Machine Learning Using the Game of Checkers", IBM Journal (1959): "Programming computers to learn from experience should eventually eliminate the need for much of this detailed programming effort"; 8–10 hours of play. (The popular "without being explicitly programmed" line is not in the paper and is not quoted.)
- T. Mitchell, _Machine Learning_ (1997): task T, performance P, experience E.
- Sahami et al., "A Bayesian Approach to Filtering Junk E-Mail" (AAAI workshop, 1998); P. Graham, "A Plan for Spam" (Aug 2002).
- Shwartz-Ziv & Armon (2021); Grinsztajn et al., NeurIPS 2022 (45 datasets).
- Hollmann et al., "Accurate predictions on small data with a tabular foundation model", Nature (Jan 2025); later TabPFN versions are vendor-reported.
- Kaggle State of Data Science and ML survey 2022 (23,997 responses; series discontinued after 2022).

Emails, rules and learned weights are a tiny illustrative example computed in the browser.
