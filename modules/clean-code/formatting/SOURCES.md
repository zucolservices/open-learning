# Sources: Formatting and style (fact-checked 2026-10-11)

- Prettier: James Long with Christopher Chedeau; first published 10 Jan 2017, 1.0 on 13 Apr 2017; current 3.9 (Prettier 4 still alpha). Biome 2.0 (17 Jun 2025).
- Black: Łukasz Langa, first release 14 Mar 2018; "The uncompromising code formatter"; 88 columns. Ruff formatter (24 Oct 2023), >99.9% Black-compatible.
- gofmt (Go, Nov 2009); Rob Pike, Go Proverbs (Gopherfest, 18 Nov 2015). rustfmt with style editions (Rust 2024).
- ESLint 8.53 (Nov 2023) deprecated formatting rules → ESLint Stylistic; flat config default in v9; v10 (Feb 2026) removed eslintrc.
- PEP 8 (5 Jul 2001): "code is read much more often than it is written".
