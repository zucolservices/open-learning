# Sources: Composition over inheritance (fact-checked 2026-10-11)

- Gamma, Helm, Johnson & Vlissides, _Design Patterns_ (Addison-Wesley, 1994; © 1995), p. 20: "Favor object composition over class inheritance"; white-box vs black-box reuse.
- Joshua Bloch, _Effective Java_ 3rd ed. (2018), Item 18 "Favor composition over inheritance"; Item 19 design and document for inheritance or else prohibit it.
- Fragile base class problem: Mikhajlov & Sekerinski (ECOOP 1998).
- Go: no type inheritance; struct embedding promotes methods (composition). Rust: no class inheritance; traits and supertraits (trait upcasting in 1.86).
