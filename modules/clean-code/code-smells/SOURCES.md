# Sources: Code smells (fact-checked 2026-10-11)

- Kent Beck coined "code smell" while helping Martin Fowler with _Refactoring_ (1999); ch. 3 "Bad Smells in Code" credited to Beck and Fowler. Fowler, "CodeSmell" bliki: "a surface indication that usually corresponds to a deeper problem in the system."
- _Refactoring_, 2nd ed. (2018): 24 smells (Long Method → Long Function; Switch Statements → Repeated Switches; new: Mysterious Name, Global Data, Mutable Data, Loops). The five-group scheme (Bloaters etc.) is from Mäntylä et al. (2003), not Fowler.
- Refactorings: Rename Function, Introduce Parameter Object, Replace Primitive with Object, Move Function, Replace Conditional with Polymorphism, Encapsulate Variable (refactoring.com catalogue).
