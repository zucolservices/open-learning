# Sources: Keep it simple (fact-checked 2026-10-11)

- YAGNI: from Kent Beck on the C3 project; first written up by Ron Jeffries, "You're NOT gonna need it!" (1998); Martin Fowler, "Yagni" (26 May 2015): costs of build, delay, carry, repair; YAGNI doesn't apply to effort that makes software easier to modify.
- Rich Hickey, "Simple Made Easy", Strange Loop, Sept 2011: simple vs easy; "complect".
- John Gall, _General Systemantics_ (1975): "A complex system that works is invariably found to have evolved from a simple system that worked."
- KISS: usually credited to Kelly Johnson (Lockheed Skunk Works); in US Navy use by about 1960 (secondary sources).
