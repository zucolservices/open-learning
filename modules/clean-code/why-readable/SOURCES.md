# Sources: Code is read more than written (fact-checked 2026-10-11)

- Robert C. Martin, _Clean Code_ (2008): reading vs writing "well over 10 to 1" (an estimate). Second edition published 30 Sep 2025 (rewrite; includes debate appendix).
- Xia, Bao, Lo, Xing, Hassan & Li, "Measuring Program Comprehension: A Large-Scale Field Study with Professionals", IEEE TSE 44(10), 2018: ~58% of time on comprehension (78 professionals, 3,148 hours).
- Minelli, Mocci & Lanza, "I Know What You Did Last Summer", ICPC 2015: ~70% comprehension, ~5% editing (18 developers, Pharo IDE).
- Cowan (2001), "The magical number 4 in short-term memory", BBS 24(1): ~3–5 chunks. Miller (1956) 7±2 described absolute judgement and memory span; chunking.
- Critiques: qntm, "It's probably time to stop recommending Clean Code" (28 Jun 2020); Casey Muratori, "Clean code, horrible performance" (28 Feb 2023, CPU-bound micro-example). John Ousterhout, _A Philosophy of Software Design_ (2018; 2nd ed 2021); Ousterhout–Martin written debate, github.com/johnousterhout/aposd-vs-clean-code (Sep 2024–Feb 2025).
