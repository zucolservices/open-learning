# Capstone: a pipeline for a payments app (CI/CD, module 21)

1. **The brief** (story): an illustrative UPI payments app; five needs.
2. **Make the choices** ⭐ (build): nine decisions (branching, tests, merge rules, artifacts, releasing, flags, migrations, credentials, dependencies), each with a note.
3. **The bad day** ⭐ (branching): eight incidents (broken commit, red builds, poisoned package, stranger's pull request, column rename, missed bug, global config change, audit); holds / degrades / breaks with explanations. No score.
4. **What to fix first** (sort checkpoint).
5. **The whole track** (wrap).
