# Storyboard: Capstone — review a messy pull request

1. **A pull request lands on your desk** (story).
2. **Choose what to read, and in what order** (branching): click five files in order.
3. **Write the comments** ⭐ (fix the problem): click lines in the diff, choose the well-labelled, kind comment.
4. **The author replies** (branching): thank, push back with facts, agree to split.
5. **Is it ready to merge?** (branching): approve when it definitely improves code health.
6. **Must fix, or fine to merge?** (checkpoint `review-capstone`).
7. **What to remember** (wrap).
