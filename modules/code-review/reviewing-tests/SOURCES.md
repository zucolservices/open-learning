# Sources: Reviewing tests (fact-checked 2026-10-11)

- Spadini, Aniche, Storey, Bruntink, Bacchelli, "When Testing Meets Code Review", ICSE 2018, doi:10.1145/3180155.3180192 — >300,000 reviews (Eclipse, OpenStack, Qt); test files less likely to be discussed; tests seen as secondary. No exact ratio quoted.
- Spadini et al., "Test-Driven Code Review: An Empirical Study", ICSE 2019, doi:10.1109/ICSE.2019.00110 — 93 developers; same production defects, more test defects, fewer maintainability issues; most prefer code first.
- Google Engineering Practices, "What to look for in a code review" (tests correct, sensible, useful).
