# Sources: What an agent is (fact-checked 2026-10-04)

- Anthropic, "Building effective agents" (E. Schluntz & B. Zhang, 19 Dec 2024): workflows vs agents; "just LLMs using tools based on environmental feedback in a loop"; start simple.
- OpenAI, "A practical guide to building agents" (April 2025): "Agents are systems that independently accomplish tasks on your behalf."
- Google, "Agents" whitepaper (J. Wiesinger, P. Marlow, V. Vuskovic, September 2024).
- S. Russell & P. Norvig, Artificial Intelligence: A Modern Approach (sensors and actuators; first edition said "effectors").
- Hugging Face smolagents docs, "Introduction to agents" (agency levels).
- Product announcements: Gemini Deep Research (Dec 2024), OpenAI deep research (Feb 2025), Claude Code (research preview Feb 2025), OpenAI Codex (May 2025), GitHub Copilot coding agent (May 2025), ChatGPT agent (Jul 2025).
