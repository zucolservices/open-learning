# Sources: Test shapes (fact-checked 2026-10-11)

- Test pyramid: Mike Cohn, sketched with Lisa Crispin c.2003–04, published in _Succeeding with Agile_ (2009); Martin Fowler, "TestPyramid" (2012); Ham Vocke, "The Practical Test Pyramid" (2018).
- Google: Simon Stewart, "Test Sizes" (2010): small/medium/large by resources; _Software Engineering at Google_ (2020) ch. 11: size and scope are independent, ~80/15/5. Mike Wacker, "Just Say No to More End-to-End Tests" (2015): 70/20/10 unit/integration/E2E (scope, not size).
- Testing Trophy: Kent C. Dodds (Feb 2018; 2021 post, designed for JavaScript UI apps). Honeycomb: Schaffer & Dybeck, Spotify Engineering (Jan 2018), microservices. Ice-cream cone: Alister Scott (Jan 2012). Fowler, "On the Diverse And Fantastical Shapes of Testing" (2021).
