# Sources: End-to-end tests (fact-checked 2026-10-11)

- Playwright (Microsoft): first release Jan 2020, 1.0 May 2020; auto-waiting and web-first assertions, codegen, Trace Viewer; Test Agents in 1.56 (Oct 2025).
- Cypress: company founded 2015, open-sourced as 1.0 on 10 Oct 2017; Cypress 16 (Sep 2026).
- Selenium 4 (13 Oct 2021); W3C WebDriver Recommendation (5 Jun 2018); WebDriver BiDi still a Working Draft (Oct 2026). Appium 3 (Aug 2025); Espresso, XCUITest, Maestro, Detox.
- Adoption: State of JS 2024 "used at work" Playwright 3,674 vs Cypress 3,603; npm downloads `@playwright/test` passed `cypress` in H2 2024 (Sep 2026 ≈261M vs 27M a month).
