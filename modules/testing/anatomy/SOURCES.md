# Sources: Anatomy of a test (fact-checked 2026-10-11)

- Arrange-Act-Assert: named by Bill Wake in 2001 (article "3A – Arrange, Act, Assert", 2011). Given-When-Then: Dan North (now Terhorst-North) and Chris Matts, from behaviour-driven development.
- xUnit family: Kent Beck's SUnit for Smalltalk (written ~1989, published Oct 1994); JUnit by Beck and Erich Gamma (1997). Current runners: JUnit 6 (Sep 2025), pytest 9, Jest 30, Vitest 5, Go `testing`, `cargo test`, Node `node:test` (stable since Node 20).

Full notes: scratchpad `sd/testing/m02-facts.md`. The basket example is made up; the assembled test runs in the browser with the track's small runner.
