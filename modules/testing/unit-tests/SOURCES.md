# Sources: Unit tests (fact-checked 2026-10-11)

- Solitary vs sociable: terms by Jay Fields, popularised by Martin Fowler, "UnitTest" bliki (May 2014).
- Michael Feathers, "A Set of Unit Testing Rules" (Artima, 9 Sep 2005): not a unit test if it talks to the database, communicates across the network, touches the file system, can't run alongside other unit tests, or needs special environment setup.
- FIRST: Tim Ottinger and Brett Schuchert, printed in Robert C. Martin, _Clean Code_ (2008) ch. 9 ("Independent"); Agile in a Flash (2009) uses "Isolated".
