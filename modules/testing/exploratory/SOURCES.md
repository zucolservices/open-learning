# Sources: Exploratory testing (fact-checked 2026-10-11)

- Cem Kaner coined "exploratory testing" in the 1980s; in print in _Testing Computer Software_ (1988).
- Jonathan Bach, "Session-Based Test Management" (Nov 2000), with James Bach; sessions typically 60–120 minutes; debriefs.
- Elisabeth Hendrickson, _Explore It!_ (Feb 2013): charter template "Explore <target> with <resources> to discover <information>"; Test Heuristics Cheat Sheet.
- Bolton (2009), Bach & Bolton, "Testing and Checking Refined" (2013; checking definition reworded Aug 2024). James Bach's Heuristic Test Strategy Model v6.3 (Dec 2024): SFDIPOT incl. Interfaces.
