## Editorial decisions

- Codec positions are qualitative and labelled "relative, not a benchmark".
- Skipping is taught with a sorted/unsorted toggle; text notes naturally ordered data also benefits.
- The nested example uses a repeated group (max r = d = 1); null vs empty lists (max d = 2) is left for a later exercise.
