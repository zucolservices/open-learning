# Storyboard: Design a lakehouse (capstone)

Track: Modern Data Lakehouse · Chapter 9 · Module 28 · ~40 min · level: applied

Brief: Sahyog Cooperative Bank (fictional): 800,000 members, 140 branches, ~3 million UPI/card transactions a day. Seven requirements: fraud data within 5 minutes, reproducible filings, member data protected, a 6-person team, fast branch dashboards, budget-conscious, data stays in India (bank policy).
