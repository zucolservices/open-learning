# Sources: Building screens (fact-checked 2026-10-12)

- SwiftUI announced WWDC 2019 (iOS 13); Observation / @Observable iOS 17 (Apple docs).
- Jetpack Compose 1.0, 28 Jul 2021 (Android Developers Blog); strong skipping default in Kotlin 2.0.20; LazyColumn composes only visible items.
- Flutter 1.0, 4 Dec 2018; ListView.builder builds only visible children.
- Apple does not document "recycling" for List; the module says lazy lists build only rows on screen.
