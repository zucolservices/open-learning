# Sources: Phones, tablets and foldables (fact-checked 2026-10-12)

- Apple HIG Layout and UITraitCollection size classes (compact/regular); safe area layout guide.
- Android window size classes: compact <600, medium 600–839, expanded 840–1199, large 1200–1599, extra-large ≥1600 dp (androidx.window 1.5.0, Sep 2025).
- Android 15 edge-to-edge; Android 16 ignores orientation/resizability limits on sw ≥600 dp for target 36 (games exempt); Android 17 removes the opt-out; Play requires target 37 from Aug 2027.
- iPadOS 26 windowing; UIRequiresFullScreen deprecated.
- Jetpack WindowManager FoldingFeature.
