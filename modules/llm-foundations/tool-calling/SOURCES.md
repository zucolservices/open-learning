# Sources (fact-checked 2026-09-25)

- OpenAI, "Introducing Structured Outputs in the API" (6 Aug 2024): gpt-4o-2024-08-06 scored 100% on complex JSON-schema following vs under 40% for gpt-4-0613. Function-calling guide (developers.openai.com/api/docs/guides/function-calling): five-step loop; `strict: true` makes calls "reliably adhere to the function schema, instead of being best effort"; `tool_choice` auto / required / specific function / none.
- Anthropic structured outputs (platform.claude.com/docs/en/build-with-claude/structured-outputs): "guarantee schema-compliant responses through constrained decoding"; GA via `output_config.format`; strict tool use. Tool definitions: `tool_choice` auto / any / tool / none.
- Google Gemini function calling (ai.google.dev/gemini-api/docs/function-calling): modes AUTO, ANY, NONE, VALIDATED; best practice "Validate function calls before executing"; structured output with JSON Schema.
- vLLM structured outputs (xgrammar, guidance, outlines backends); llama.cpp GBNF grammars and JSON-schema conversion; Outlines (dottxt-ai).
- Model Context Protocol: announced by Anthropic 25 Nov 2024; donated to the Agentic AI Foundation (Linux Foundation directed fund co-founded by Anthropic, Block and OpenAI) on 9 Dec 2025; spec: "Hosts must obtain explicit user consent before invoking any tool" (current spec 2026-07-28).
- Model data: onnx-community/Qwen2.5-1.5B-Instruct (fp16 ONNX, Transformers.js v4). Next-token probabilities are exact softmax values at the given JSON prefix; "schema enforced" renormalises over vocabulary tokens that are prefixes of an allowed value (a simplified view of grammar-constrained decoding). Tool-calling replies use Qwen's own chat template with tools, greedy decoding; the "forced" run prefills `<tool_call>` (what tool_choice=required does in effect). Tool results, orders and the company are invented.
