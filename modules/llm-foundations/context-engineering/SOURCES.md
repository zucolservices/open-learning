# Sources (fact-checked 2026-09-25)

- Liu et al., "Lost in the Middle: How Language Models Use Long Contexts" (arXiv 2307.03172, TACL 2024). Table 6 (20-document multi-document QA, gold at positions 1/5/10/15/20): GPT-3.5-Turbo 75.8 / 57.2 / 53.8 / 55.4 / 63.2; Claude-1.3 59.9 / 55.9 / 56.8 / 57.2 / 60.1; LongChat-13B (16K) 68.6 / 57.4 / 55.3 / 52.5 / 55.0; MPT-30B-Instruct 53.7 / 51.8 / 52.2 / 52.7 / 56.3. Table 1: GPT-3.5-Turbo closed-book 56.1%, oracle 88.3%.
- Hong, Troynikov and Huber, "Context Rot" (Chroma, 14 Jul 2025; 18 models): "Across all experiments, model performance consistently degrades with increasing input length"; lower needle–question similarity and distractors increase degradation.
- Anthropic prompting best practices: long documents at the top, query at the end ("up to 30 percent" better on complex multi-document inputs).
- Prompt caching (Sep 2026): Anthropic cache reads 0.1× base input on Sonnet 5 (0.05× Opus 5.5), 5-minute writes 1.25×, 1-hour writes 2×, default TTL 5 minutes; OpenAI GPT-5.6 and later: reads 0.1×, writes 1.25×, 1,024-token minimum; Gemini implicit caching on by default for 2.5 and newer. Price used: $2 per million input tokens (Claude Sonnet 5, gpt-6-sol).
- Real runs: onnx-community/Qwen2.5-1.5B-Instruct, 4-bit ONNX (Transformers.js v4), greedy decoding. Invented help-centre articles (one per Bengaluru area) with 3 Sunday-closed areas at random positions; 12 runs per condition. The search condition scores the 30 articles by overlap with the question's words and keeps the top 5. An easier single-fact lookup (one minimum-order question over 20–40 articles) was answered correctly at every position we tried, which is why the harder "find them all" task is shown.
- Token sizes in "Fill the window" and the memory comparison are illustrative.
