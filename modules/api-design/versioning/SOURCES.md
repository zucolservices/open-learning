# Sources: Versioning and breaking changes (fact-checked 2026-10-04)

- Semantic Versioning 2.0.0: "MAJOR version when you make incompatible API changes": https://semver.org/
- Stripe API versioning (Stripe-Version; monthly non-breaking versions and two major releases a year since 2024-09-30.acacia; current 2026-09-30.endive): https://docs.stripe.com/api/versioning , https://docs.stripe.com/upgrades
- Brandur Leach, "APIs as infrastructure: future-proofing Stripe with versioning" (5 Aug 2017): https://stripe.com/blog/api-versioning
- GitHub REST API versions (X-GitHub-Api-Version; 2022-11-28 and 2026-03-10; at least 24 months support): https://docs.github.com/en/rest/about-the-rest-api/api-versions
- Google AIP-185 (versioning) and AIP-180 (backwards compatibility): https://google.aip.dev/185 , https://google.aip.dev/180
- Azure REST API guidelines (required api-version, YYYY-MM-DD).
- Martin Fowler, "TolerantReader" (9 May 2011): https://martinfowler.com/bliki/TolerantReader.html
- Zalando guidelines #106, #107, #113.

The members API and its changes are illustrative.
