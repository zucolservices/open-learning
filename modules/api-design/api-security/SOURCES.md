# Sources: Authorisation and API security (fact-checked 2026-10-04)

- OWASP API Security Top 10 2023 (latest edition), API1 prevention: "Use the authorization mechanism to check if the logged-in user has access to perform the requested action on the record in every function that uses an input from the client to access a record in the database.": https://owasp.org/API-Security/editions/2023/en/0x11-t10/
- OWASP Mass Assignment Cheat Sheet (allow-list bindable fields; DTOs).
- Optus: OAIC media release (8 Aug 2025, about 9.5 million Australians); ACMA statement (alleged access-control coding error on an unused API domain; "not highly sophisticated"); proceedings ongoing.
- T-Mobile Form 8-K (19 Jan 2023): "a bad actor was obtaining data through a single Application Programming Interface ("API") without authorization", about 37 million customer accounts.
- Pen Test Partners, Peloton API research (5 May 2021).
- GitHub blog, "Public Key Security Vulnerability and Mitigation" (4 Mar 2012).

The parcel API, its holes and data are illustrative.
