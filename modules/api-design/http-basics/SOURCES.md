# Sources: HTTP from the ground up (fact-checked 2026-10-03)

- RFC 9110 "HTTP Semantics" (June 2022, STD 97): https://www.rfc-editor.org/rfc/rfc9110 (§3.3 stateless; §9.2.1 safe "essentially read-only"; §9.2.2 "PUT, DELETE, and safe request methods are idempotent."; §15 status classes; field names case-insensitive).
- RFC 9111 (caching), RFC 9112 (HTTP/1.1), RFC 9113 (HTTP/2, lowercase field names), RFC 9114 (HTTP/3), all June 2022; RFC 9000 QUIC (May 2021).
- RFC 10008 "The HTTP QUERY Method" (June 2026): https://www.rfc-editor.org/rfc/rfc10008
- "The Original HTTP as defined in 1991", Tim Berners-Lee: https://www.w3.org/Protocols/HTTP/AsImplemented.html
- Cloudflare 2025 Year in Review (15 Dec 2025): 50% HTTP/2, 29% HTTP/1.x, 21% HTTP/3 of requests to Cloudflare.
