# Sources: REST, RPC, GraphQL and events (fact-checked 2026-10-03)

- Roy T. Fielding, "Architectural Styles and the Design of Network-based Software Architectures", PhD dissertation, UC Irvine, 2000, ch. 5: https://ics.uci.edu/~fielding/pubs/dissertation/rest_arch_style.htm
- gRPC: grew from Google's internal Stubby, open-sourced 2015, HTTP/2 + Protocol Buffers; CNCF Incubating since 16 Feb 2017: https://grpc.io/about/ , https://www.cncf.io/projects/grpc/
- GraphQL: created at Facebook 2012, open-sourced 2015, GraphQL Foundation (Linux Foundation) 2019; spec edition September 2025: https://graphql.org/ , https://spec.graphql.org/
- Jeff Lindsay, "Web hooks to revolutionize the web", 3 May 2007 ("user defined callbacks made with HTTP POST").
- SOAP 1.2 W3C Recommendation, 24 June 2003 (Second Edition 27 April 2007): https://www.w3.org/TR/soap12/
- Postman 2025 State of the API Report (5,700+ respondents): REST 93%, webhooks 50%, WebSockets 35%, GraphQL 33%, SOAP 25%, gRPC 14%: https://www.postman.com/state-of-api/
- Model Context Protocol spec: messages "MUST follow the JSON-RPC 2.0 specification": https://modelcontextprotocol.io/specification

Sample requests are illustrative.
