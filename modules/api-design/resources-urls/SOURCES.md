# Sources: Resources and URLs (fact-checked 2026-10-03)

- Fielding, "REST APIs must be hypertext-driven" (2008): https://roy.gbiv.com/untangled/2008/rest-apis-must-be-hypertext-driven

- RFC 3986 URI Generic Syntax (§3 components; §6.2.2.1 case): https://www.rfc-editor.org/rfc/rfc3986
- Google AIP-121, 122 (camelCase collection IDs), 131–135, 136 (":archive"): https://google.aip.dev/
- Zalando RESTful API Guidelines: #129 "MUST use kebab-case for path segments", #130 snake_case query parameters, #134 plural, #141 "MUST keep URLs verb-free", #147 "<= 3 sub-resource (nesting) levels": https://opensource.zalando.com/restful-api-guidelines/
