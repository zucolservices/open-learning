# Storyboard: Capstone, untangle a team's messy repository

1. **Monday morning** (story): main after a stale clone's force-push; three commits unreachable.
2. **Rescue the lost work** ⭐ (fix-the-problem): find the old tip (reflog/clone or push log vs dead ends), then restore it (rescue-branch merge, cherry-pick, force-push back) and watch the graph.
3. **Undo or rewrite?** (branching scenario): five situations, revert vs rewrite.
4. **Set the rules** (explore): toggle guardrails, replay the month's incidents.
5. **The whole track as a checklist**.
6. **Put the rescue in order** (checkpoint `git-capstone`).
7. **What to remember** (wrap).
