# Storyboard: Snapshots, not differences

1. **Photos, not a diary** (story): whole-room photos; shared prints.
2. **Build a commit by hand** ⭐ (build): three files → blobs → tree → commit with real SHA-1 IDs computed in the browser; edit a file or make two identical and watch IDs change or merge.
3. **The second snapshot** (explore): a second commit reuses unchanged blobs; packfiles mentioned.
4. **A fingerprint for every object** (explore): content addressing, SHA-1 hardening, SHA-256, Git 3.0 plans.
5. **True or false?** (checkpoint `git-snapshots`).
6. **What to remember** (wrap).
