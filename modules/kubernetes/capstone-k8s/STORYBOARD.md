1. **The brief** (story): an illustrative payments API on a three-zone managed cluster; always up, festival surges, safe releases, locked down, routine operations.
2. **Make the choices** ⭐ (build): nine decisions (replicas, rollout, probes, resources, autoscaling, PDB, service account, pod security, database password), each linked to its module with a note.
3. **The bad day** ⭐ (branching scenario): seven incidents (bad release, node dies, zone outage, surge, drain, compromised pod, database blip) with holds / degrades / breaks and explanations; Reddit 2023 and Monzo 2017 as real-world echoes. No score.

5. **The whole track** (wrap).
