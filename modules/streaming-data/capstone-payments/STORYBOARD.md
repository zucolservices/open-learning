# Capstone: a real-time payments monitor (Streaming Data Systems, module 23)

1. **The brief** (story): an illustrative UPI payments app; scale, fraud velocity checks, merchant dashboard, audit, no silent loss; Razorpay as a real-world reference.
2. **Make the choices** ⭐ (build): eight decisions (key, partitions, replication, schemas, guarantee, time, bad events, storage), each linked to its module, with a note on what it buys.
3. **Break it** ⭐ (branching scenario): seven failures (broker, job crash, schema change, malformed event, festival spike, late phones, merchant check); pipeline stage highlighted; holds / degrades / breaks with explanation and module link; failures combine (schema → bad-event handling). No score.
4. **What to fix first** (sort checkpoint): before launch vs improve later.
5. **The whole track** (wrap): seven chapters and the habits that carry over.
